# Hydration Buddy

This is a static, single-page browser app. Open `index.html` locally, or publish this folder to a static site host to share it.

## Publish with Netlify Drop

1. Sign in to Netlify and open its manual deploy page: https://app.netlify.com/drop
2. Drag the `hydration-buddy-site` folder onto the deploy area.
3. Netlify will provide an HTTPS link you can share.

The app has no server or account system. Drink logs and goals stay in each visitor's browser storage on that device. City searches go to Open-Meteo. Browser speech recognition may process microphone audio through the browser's recognition service; voice is optional. Review the privacy notice in the app before sharing it broadly.

## Health guidance

Hydration targets are general guidance, not a medical plan. Visitors should use targets or fluid limits set by their own healthcare team.
